Finding your lighting host

Scanning the network and reconnecting to your trusted lighting PC. Saved sign-in details are used automatically.

On the host, open Settings → LAN & accounts and allow Windows firewall access. The host must be running. Direct IP works over a routed VPN; automatic discovery also requires broadcasts or a resolvable host computer name.

First connection asks you to trust the host certificate, then sign in using an account created on that host.
