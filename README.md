# LifeAC Lighting 0.7.0

Windows lighting control for Life Anglican Church. Close the old app from its tray before updating. Shows, profiles, accounts, MIDI mappings and photo positions are retained. Drivers, projector setup and Welcome app are unchanged.

Run Setup to choose Primary, Backup or Network Controller. Updater preserves that role. Network Controller has no USB/MIDI host components; it discovers available hosts when choosing a connection. Remote clients sign in with a host account and verify its certificate fingerprint. Discovery depends on LAN/firewall access; manual HTTPS entry remains available.

First launch asks about starting at Windows sign-in; Settings and the tray can change this. Primary opens its UI, Backup starts quietly. The supervised independent host owns USB/MIDI/timing and continues after client windows close. Windows must remain powered and signed in. Explicit tray shutdown ends output. Keep loopMIDI and ProPresenter running in the host account. Saved MIDI ports reconnect automatically; mappings are on scene right-click menus and in Settings. Input and scene decisions are logged.

For failover choose the same trusted, directly accessible shared folder in Primary and Backup Settings. Open quiet Backup through its tray to configure it. Primary saves changed configuration initially, hourly and on orderly shutdown. A separate heartbeat carries the latest scene and mute/dark state. Backup verifies/imports configuration, waits for heartbeat loss (about 12 seconds), starts LAN hosting and acquires USB when physically switched/connected. It never switches hardware. Active backup operation is not overwritten by primary configuration. Salted account/PIN hashes are shared; protect the folder. Cloud sync delays can affect availability detection. Sudden power loss can lose changes since the last configuration save.

Scenes are left; the stage photo is right. Sunday Services is default. Left-click runs a scene; right-click opens actions. Initial Admin PIN is 5433; change it in Settings. Admins drag six-dot handles to reorder, or Ctrl/Shift-click several scenes for bulk move/delete/combine. New Folder is at the bottom of the dropdown. Procedural effects cannot be combined automatically.

Select fixtures/groups on the picture for shared controls below; click its background to deselect. Each fixture has a percentage dimmer (hardware/software), a hex colour picker where supported and separate UV on known UV fixtures. Manual values hold through scene/MIDI cues until saved or released; host shutdown ends holds. Release Custom clears holds and returns to the running scene. Release All refreshes dark emitter levels while retaining USB/movement/function channels. A new cue resumes scene output. 11am mutes its configured fixtures after all scene/manual processing; Admin right-click configures that group on the photo.

Save opens scene tiles and a fixture picture. Choose destination scenes across folders. Existing-scene saves start with no fixtures selected; New Scene automatically selects all, and selection can be changed. Selected values update every destination step, preserving other fixtures and timing. Saved values exclude temporary 11am mute. Saving an unrelated scene does not cue it.

Settings contains profiles, placement, accounts, MIDI, diagnostics, startup and failover. Setup/placement lists only unplaced fixtures. In Arrange stage photo select one, control it to identify it, then click its place; drag existing pins to move. Admin right-click pins for name/model/address setup. Moving heads offer Teach L/R and U/D: use the raw pad and record Centre/Left/Right/Up/Down in actual stage directions, including skewed mounts. Normal cross-pad movement supports diagonals and clamps to channel limits. Save/release identification and calibration holds afterward.

Logs: %LOCALAPPDATA%\LifeAC-Lighting\logs. Settings > Export diagnostics includes redacted retained logs; nothing uploads automatically. Scene checkpoints retain compatible playback through reconnect/recovery without silently choosing a default scene.

Standalone reads remain experimental; partial reads are retained. Full verified restoration and memory writing are unavailable. Ordinary DMX output cannot self-report fixture names/models; these come from the configured project.

See docs/RELEASE-NOTES.md and docs/VALIDATION.md. Development checks use simulation without laptop USB/MIDI or an installed host. Actual lights, LAN and physical failover need the church PCs.
