# LifeAC Lighting 0.8.1

Windows church lighting control with an independent USB/MIDI host and local/LAN desktop clients.

**Small download:** run `LifeAC-Lighting-Updater.exe` for either installation or updates. If the app is missing, choose Primary, Backup or Network Controller; the updater downloads and installs the latest application. Existing installations retain their role and show. Close Lighting from its tray before updating.

Use the new Setup or Updater from the Life-Anglican-Church/Lighting release page once to replace the updater credential invalidated by the repository transfer. Close Lighting from its tray first. Install over the existing copy to preserve shows, layouts, accounts and mappings. Setup chooses Primary, Backup or Network Controller; the updater preserves that role. Update both host and controllers to 0.8.1. Host installation refreshes Windows LAN/VPN rules after administrator approval. Network Controllers discover the current host address at startup, then reuse Windows-encrypted credentials matched to its trusted certificate. Bare IPs/computer names use HTTPS port 47832. VPNs must route that port; broadcast discovery needs broadcast support or a resolvable remembered host name. Network Controller installs only the client and can discover or manually connect to a host. Host components are excluded; explicit conversion to Network Controller clears older release folders and the app's cached USB SDK.

The reference-based console uses your original church logo, stage photo and scenes. Scenes are on the left, the stage and fixture-group buttons centrally, and tabbed Colour/Movement/Advanced controls on the right. Select lamps or groups to edit their common controls. Ctrl/Shift-click group buttons for combined selection. Fixture icons preview commanded output colours and intensity; they do not measure physical light output. Left navigation includes a scene library, the full Fixtures/DMX patch editor, Groups and Settings. Dark mode is default, and the theme switch is remembered on each client.

Global master scales output intensity without changing scene values or movement/function channels. MIDI mute suppresses ProPresenter scene cues while keeping the host MIDI input connected; current playback and manual control continue. ProPresenter status represents loopMIDI/MIDI input availability. It does not claim a direct ProPresenter API connection. Keep loopMIDI and ProPresenter running on the host's Windows account. Both master and cue-mute states recover with compatible playback and pass to standby; a clean host shutdown resets them.

Manual fixture values stay held through scene and MIDI cues until saved/released or host shutdown. Release Custom restores the running scene's values. Release All keeps USB but forces known emitters dark; a new scene cue resumes scene output. 11am remains the configured fixture mute. Admins configure it using photo selection. Top-right Disconnect DMX requires fresh confirmation with the Admin PIN. Default Admin PIN remains 5433 unless already changed in your show data.

Save supports multiple destination scene tiles across folders, with fixture selection on the picture. Existing-scene saves start with no fixtures selected; New Scene selects all, then allows you to change that selection. Other fixtures/timing are retained. Temporary 11am/global master processing is excluded from the saved values. Ctrl/Shift-select scene tiles for bulk move/delete/combine; right-click for scene-specific editing and ProPresenter note mapping. Folder order is configurable in Settings or the Scenes library.

Fixtures includes all configured lights, channel map, model/name/patch settings, additions/imports and DMX-level controls. Function/reset/protected channels are read-only. Configure photo placement under Settings: only unplaced fixtures are listed; live controls identify each one before positioning. Moving-head direction teaching records Centre/Left/Right/Up/Down in actual stage directions, including skewed mounts, and supports diagonal pad motion. UV remains separate from normal colour mixing.

For LAN: on Primary, create an account in Settings → LAN & accounts. Network clients first connect to HTTPS, compare/trust the host certificate fingerprint, then enter that username/password. Their account password is separate from the Admin PIN. Certificate choices and client session data are stored locally. A visible connection screen offers retry and host selection after failure. Local automatic host authentication never works over LAN. Use a Private Windows network. Host installation can request Windows approval for local-subnet inbound TCP 47832/UDP 47833; Settings offers the same firewall action. Actual network/firewall policy can still prevent discovery; manual HTTPS entry is available.

Startup is optional at Windows sign-in, asked on first launch and configurable in Settings/tray. Primary opens its UI; Backup starts quietly. The supervised host continues USB/MIDI after UI windows close. Windows must remain powered and signed in. The app does not run as a pre-login Windows service.

For standby, choose the same trusted, directly accessible shared folder in Primary and Backup Settings. Primary saves changed configuration initially, hourly and on orderly shutdown; a separate heartbeat carries the latest scene and live mute/master state. Backup imports verified configuration, waits about 12 seconds after heartbeat loss, then acquires USB when physically connected/switched and offers LAN hosting. It never switches hardware. Active backup playback is not overwritten by incoming configuration. Cloud-sync delays can affect availability detection; a sudden failure may miss configuration changes since the last shared save. Account/PIN hashes are included in the trusted share.

Logs and show data are under %LOCALAPPDATA%\LifeAC-Lighting. Settings > Export diagnostics includes redacted retained logs. There is no activity-log panel and nothing uploads automatically. Full uninstall now removes the application's local data, including local shows/backups/accounts/cache, as well as installed releases, shortcuts/startup and app-created firewall entries. Shared-folder copies, other applications, installers you downloaded and shared USB drivers are retained. Install over the current version when you want to preserve show data.

Standalone reads remain experimental; partial exports are retained. Verified full restoration and memory writing remain unavailable. Ordinary DMX output cannot self-report fixture identities; names/models come from the configured project.

See docs/RELEASE-NOTES.md and docs/VALIDATION.md. Development verification uses simulation, temporary test fixtures and loopback HTTPS. No physical USB/MIDI, installed host, actual installer/uninstaller or firewall changes were run on the laptop.
