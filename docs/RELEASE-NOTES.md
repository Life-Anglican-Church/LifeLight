# LifeAC Lighting 0.7.0 — Backup failover and photo control desk

Close Lighting from its tray before updating each PC. The updater retains its role, show, accounts, mappings and photo positions. Use the new Setup installer to choose or change a PC role.

- **Primary / Backup / Network Controller:** three installer choices. Primary owns USB/MIDI and opens its UI. Backup starts quietly, prepares the shared show and waits for Primary to go offline and USB to become available. Network Controller installs only the client and discovers LAN lighting hosts; manual HTTPS entry remains. Remote clients still need an account and certificate verification.
- **Startup:** first launch asks whether to start at Windows sign-in. Change it in Settings or the tray menu. Primary opens its UI; Backup stays in the tray. The independent engine keeps USB/MIDI running after its UI closes and is supervised for restart. Windows must remain powered and signed in; this is not a pre-login Windows service.
- **Shared-folder failover:** choose the same trusted shared folder in Primary and Backup Settings. Open quiet Backup through its tray to configure it. Primary saves changed configuration initially, hourly and on orderly shutdown. A separate heartbeat carries the latest scene and dark/11am state. Backup verifies configuration before importing, starts LAN hosting and attempts USB takeover after heartbeat loss (about 12 seconds). It does not operate a physical USB switch. Active Backup operation is not overwritten by incoming Primary configuration. Accounts/PIN are synchronized as salted hashes; treat this folder as trusted configuration storage. Use a directly accessible share: cloud sync delays can affect availability detection. Sudden power loss can lose configuration changes since the last shared save.
- **Picture-only operation:** select/control fixtures on the stage picture. Removed individual-light lists from routine controls, scene editing, mute/group selection and saving. Setup/placement list only unplaced fixtures. Existing pins remain selectable for live identification while arranging. Admins right-click a pin for fixture setup.
- **Control desk:** colour wheel left, neighbouring movement/faders right, consistent buttons and inline folder dropdown. Removed stray arrows and shared-window count. New Folder is at the bottom of the main folder dropdown.
- **Release All** retains USB and refreshes a dark frame for known emitters, preserving position/function channels. **Release Custom** clears manual holds and returns to the running scene. A new scene/MIDI cue resumes normal scene output after Release All.
- **Save to several scenes:** scene tiles/folders left and fixture picture right. Existing-scene saves start with no fixtures selected. New Scene automatically selects all fixtures; selection can then be changed. Choose several destination scenes across folders. Only selected fixtures are copied; other fixtures and scene timing remain intact. Saving an unrelated scene does not change the playing scene.
- **Taught moving-head directions:** Admin right-click a moving-head pin, then Teach L/R and U/D. Aim it with the raw pad and record Centre, Left, Right, Up and Down. Directions may be angled/skewed, without a square assumption. The normal cross pad labels L/R/U/D and supports diagonals. Physical/channel limits still apply. Calibration creates live manual holds; save or release them afterward.
- **Scene organization:** Ctrl/Shift-click several tiles; right-click for bulk move/delete or combine compatible static/timed scenes into a timed loop. Procedural-effect scenes need separate editing. Fixed drop slots prevent rapid back-and-forth reordering while neighbouring tiles animate; the dragged tile follows the pointer.
- **Recovery:** manual holds and 11am remain host-owned. Release All dark state survives same-session host recovery and passes to standby, avoiding unexpected relighting. Existing UV faders/profile corrections remain included.

Validation: 49 automated tests, current Windows simulation UI flow and hidden Electron startup/independent-host checks pass. Native application/helpers compile. Package/download hashes are checked before release. No physical USB/MIDI or installer was run on the laptop. Real two-PC discovery, share timing and USB handover need an on-site check.

Standalone memory writing remains disabled; no verified full read/write restoration path is claimed. Ordinary output-only DMX does not discover fixture identities.
