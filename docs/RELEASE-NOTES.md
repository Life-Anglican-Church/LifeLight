# LifeAC Lighting 0.6.1 — UV faders and fixture profile correction

Close Lighting from its tray menu, then run the updater on the host and control PCs. Existing shows migrate automatically with a backup. Fixture names, models, addresses, groups, positions and scene values are retained.

- The original ProDMX project explicitly names UV channels that had been classified as amber. The six Beamz HexCans use UV channels 6 and 12; the AVE HexFlat uses UV channel 8 (fixture-relative channel numbers). Their true amber channels remain amber. This is configured profile data, not fixture identity discovery over DMX.
- These seven configured UV-capable lights now have a separate purple-accented 0–100% UV fader in the bottom control desk, scene editor, fixture controls and placement configurator. Each HexCan's two UV banks are linked to one fader. Multi-selection offers one shared UV fader when all selected fixtures support UV, including mixed 8/16-bit channels.
- The RGB colour palette leaves UV channels separate. UV levels can be held manually across scene/MIDI changes, saved into scenes and released with the other controls. The software dimmer scales emitter faders as a master, so a UV fader retains its setting while Dimmer changes; raising UV does not force it back to the master's full level. UV fader values display before the software master, matching hardware fixture-channel controls.
- UV participates in software dimming, fades, brightness pulses and the final 11am fixture mute. Muted UV emitters cannot be relit by manual faders or scene changes. Movement, shutter and protected/function channels remain excluded from manual UV control.
- UV correction applies to the existing installed show, imported ProDMX shows, fixture-profile imports and restored show data. Only explicitly named, known emitter channels are corrected. Ambiguous combined Amber/UV and protected/function channels are not guessed. Saved scenes retain their existing channel values.

Validation: 45 automated tests pass, including the actual church project's UV/amber map, existing-show migration/backups, linked UV banks, mixed channel depths, fade/hold/dimmer/pulse/mute behaviour and scene capture. Windows UI checks cover UV control on both banks, mixed Beamz/AVE selections, colour-picker separation, correct UV fader readback under the software dimmer, live scene editing/saving, 11am mute, fixture settings and placement controls. Existing dashboard and colour-desk flows pass. No physical USB/MIDI or installer is opened on the laptop. The on-site UV response still needs the projector PC.

The Windows host/client architecture and v0.6.0 scene-recovery fixes are retained. Standalone memory writing remains disabled.
