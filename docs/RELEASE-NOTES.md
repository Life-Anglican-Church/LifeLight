# LifeAC Lighting 0.8.0 — New control console and LAN fixes

Lightweight updater revision: **LifeAC-Lighting-Updater.exe** also installs the app when missing, with Primary, Backup and Network Controller choices. It downloads the application automatically. Existing installations retain their show and PC role. The new updater is kept in the installed application for future updates.

Install this version over the existing copy to keep your show. Close Lighting from its tray before updating. Download the new Setup or Updater from this release once: the previous updater's credential stopped working when the repositories moved to the organisation. Both new executables use Life-Anglican-Church/Lighting and the replacement read-only credential.

- **Rebuilt console:** a new screen structure and a single new stylesheet based on the supplied reference. Left navigation has Control, Scenes, Fixtures, Groups and Settings. Original church logo, stage photo, scene names, fixture patch, layouts, mappings and saved looks are retained. Two-column tinted scene tiles sit left; the stage and group buttons are central; fixture controls are in the right panel. Colour, Movement and Advanced tabs keep the controls together. Dark mode is default, with a remembered light/dark switch.
- **Global master:** live 0–100% output control in the bottom bar. Hardware dimmers are scaled where available; colour-only fixtures scale their emitter channels. Eight/sixteen-bit channels and UV are supported. Movement, shutter and protected channels are retained. Levels are not baked into saved scene looks. Master state survives compatible same-session recovery and standby handover; orderly host shutdown resets it to 100%.
- **ProPresenter and MIDI mute:** one ProPresenter status card replaces the separate MIDI status label. It represents the host's loopMIDI/MIDI input, not a separate ProPresenter API. MIDI mute ignores incoming scene cues while keeping the input connected and counting messages. Current playback, manual scene selection and fixture controls continue. Unmuting accepts future cues without replaying ignored cues. It is retained through compatible recovery/standby and resets on orderly shutdown. There is no activity-log panel or manual-override button; diagnostic export and held manual controls remain available.
- **Fixture groups and icons:** group buttons beneath the stage select member lights together. Click another group to switch, or Ctrl/Shift-click to combine selections. Groups can be created/edited from the Groups section. Individual lamp icons remain visible, using colours calculated from the final commanded DMX output, including dimming and mute. These are approximate previews, not physical light telemetry. Nothing in the preview seeds a new stage layout or groups into your existing show.
- **Fixtures:** the full fixture list is available in Fixtures, with a 512-channel universe map, patch/name/model editing, adding lights and importing profiles. DMX channel controls expose known safe analog channels; function/reset/protected channels remain read-only. Placement configuration still lists only unplaced lights and supports live identification. UV remains a separate Advanced control. Taught L/R/U/D movement and diagonal control are retained.
- **Folders and disconnect:** folder order is configurable under Settings or the Scenes library and shared across clients. Disconnect DMX is top-right, with a fresh Admin PIN confirmation even if Admin mode is already unlocked. A refused/missing PIN leaves live output running. Release All refreshes dark emitter output while keeping USB; Release Custom returns manual values to the current scene. Multi-scene Save retains its existing defaults: no fixtures for existing destinations, all fixtures for New Scene.
- **LAN discovery:** searches each active IPv4 interface using directed broadcasts/retries and advertises the address matching the requesting network. HTTPS listens on the host's interfaces and validates its Host headers. Failed listener startup can retry. Host installation offers Windows approval for Private-network, local-subnet TCP 47832 and UDP 47833 firewall rules; Settings can request this again. No network profile is changed automatically. Manual address entry remains available.
- **Network controller connection:** a local loading screen appears immediately. Connection failure shows retry and host selection instead of a blank blue window. Exact host certificates can be remembered after fingerprint confirmation. Once HTTPS connects, the username/password form appears. Create remote accounts on Primary in Settings → LAN & accounts; the Admin PIN is separate. Local automatic bootstrap is refused over HTTPS. Client windows use a persistent application session/cache folder.
- **Roles and uninstall:** Network Controller excludes USB/MIDI/server/Node-host components, and the launcher enforces its role even if a marker is absent. Selecting Network Controller in Setup removes older installed release folders and the application's cached USB SDK. Normal client updates do not attempt to delete the running updater. The full uninstaller removes the application, old releases, local show/settings/accounts/backups/logs/cache, startup/shortcut entries and app-created firewall rules; it also cleans its temporary helper. Shared-folder copies, other apps, downloaded installers and shared device drivers are retained. Export anything you want to keep before a full uninstall; normal installation over the existing version preserves show data.

Validation: 57 automated tests pass. Windows browser flows cover the console, groups, tabs, global master, MIDI mute, safe channel editor, scene/folder actions and save defaults. A real hidden Electron client checks the connection error/retry screen, remembered certificate, HTTPS credential login and a remote scene cue against an independent simulated host. Installation filtering, release pruning and app-data deletion are checked in compiled tests against temporary fixtures. Native helpers/installer/updater compile and release hashes are verified. Actual cross-PC firewall/discovery and physical USB/MIDI behaviour still need an on-site check; no installer or real USB/MIDI/firewall changes were run on the laptop.

Standalone full restoration and memory writing remain unavailable; this release preserves experimental read/export support.
